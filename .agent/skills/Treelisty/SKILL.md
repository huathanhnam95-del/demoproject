# TreeListy Skill

A structural tool for decomposing complex hierarchies—perfect for **Skill Tree Designing**.

## When to Use

- **Skill Tree Architecture**: Designing branching unlockable abilities.
- **Quest Deconstruction**: Breaking main quests into sub-objectives.
- **World Hierarchy**: Managing zones, rooms, and items.

## Patterns

- `roadmap`: For game development milestones.
- `generic`: Default hierarchy for custom RPG structures.
- `visualize`: Export trees to **Mermaid diagrams** for game design documentation.

## Commands

- `decompose`: Create structured trees from text input.
- `export --format mermaid`: Generate visual diagrams of your skill trees.
- `validate`: Check tree quality and balance.
