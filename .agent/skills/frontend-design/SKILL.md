# Frontend art direction

Choose a coherent visual direction grounded in the audience, content and task. Inspect existing brand assets, components and implementation constraints first. For work inside an established product, express the direction through its visual language unless a broader redesign is authorized.

## Compose deliberately

- Establish hierarchy through type scale, spacing, placement and contrast before decoration. Use realistic content and meaningful imagery.
- Choose typography for legibility, character, language coverage, licensing and loading cost. Inter, system fonts and other familiar choices are valid when they fit; no font is universally forbidden.
- Use a restrained palette and consistent spacing with a few deliberate accents. Density should serve the task, whether a dense professional tool or an editorial page.
- Prefer clear composition to layers of nested cards, repeated gradients or arbitrary ornamental effects. Rich styling is useful when it reinforces the intended experience.
- Make motion explain transitions or guide attention. Preserve reduced-motion behavior and avoid costly effects that compromise interaction.
- Carry the direction through responsive layouts, realistic long text and all important interaction states.

For searchable style, color or typography options use [UI UX Pro Max](../ui-ux-pro-max/SKILL.md). Treat its output as inspiration filtered through the actual context. For component mechanics use [ui-design](../ui-design/SKILL.md); for unresolved user journeys use [ui-ux-designer](../ui-ux-designer/SKILL.md).

## Produce and verify

Deliver the artifact requested: a concept, implementation or focused revision. Use the existing stack and components unless changing them is in scope. Generated or sourced assets must be available in the delivered artifact, and claims about their provenance must be accurate.

Inspect the rendered result with the project's verification workflow. Check hierarchy, content fit, contrast, focus, responsive behavior and relevant states. Explain the few visual decisions that matter and any verification limits. Do not add a separate branding exercise to a small UI fix. [Provenance](SOURCE.md).
