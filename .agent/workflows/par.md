# PAR: Push All Readied

When the user invokes PAR, read and execute the complete [release protocol](../rules/session_tagging.md) and [parallel-work safety policy](../rules/parallel-work-safety.md).

Discover ready tasks from native task lists, shared readiness records, and verified completed worktree handoffs. Recheck readiness, freeze the eligible batch, integrate sequentially into the established main worktree, verify, commit, push, reconcile current production, deploy the recorded targets, and verify live. The explicit PAR command authorizes these normal stages. Only fully verified deployments receive `(D)`.

Use supported host-specific task tools and verified identities. Do not run Antigravity helpers against Codex or another host. Report blockers, missing discovery coverage, partial releases, and remaining ready work accurately. This workflow does not authorize unrelated projects, destructive data operations, or worktree deletion.
