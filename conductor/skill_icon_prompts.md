# LingoRPG Skill Icon Prompts (Dragon Nest-Style, Active Blue / Passive Gold)

These prompts are written to help an artist (or an image model) create a consistent icon set inspired by Dragon Nest's "hand-painted HQ" skill icons, adapted to LingoRPG.

## Global style constraints (apply to every prompt)

- Format: **256x256** icon, designed to remain readable when downscaled to **44x44** inside a circular orb.
- Technique: **hand-painted / digital painting** look (not flat vector), with realistic-ish textures (metal, leather, parchment, crystal, magic aura).
- Composition: one clear **central silhouette** + strong **motion/force cues** (swirl, slash, burst, shockwave, ripple).
- Lighting: strong **internal glow** + bright hotspots + dark vignette (high contrast).
- Background: keep it simple; use a subtle radial gradient + vignette. Prefer **transparent background** if possible (UI provides the frame/orb).
- No readable text. Abstract runes/glyphs are OK if they are not legible words.
- Avoid: characters/faces, logos, UI frames, long thin details that vanish at small size.

### Color rule (hard constraint)
- **Active skills**: dominant **blue/cyan** energy palette (blue glow, lightning, frost, arcane).
- **Passive skills**: dominant **gold/yellow/white** palette (holy light, radiant metal, warm aura).

### Optional per-core-skill motif (subtle, not dominant)
- Listening: sound waves, echo rings, resonance lines.
- Writing: ink strokes, quill feathers, punctuation ghosts.
- Reading: parchment, lens, highlight beams.
- Speaking: waveform breath, voice sigils, echo trails.
