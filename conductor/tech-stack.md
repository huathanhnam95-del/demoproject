# Technology Stack

## Core Technologies

- **Language**: JavaScript/HTML/CSS, Python
- **Frontend Framework**: Vanilla JS, HTML5, CSS3
- **Backend Framework**: Flask / Cloud Functions / Kokoro-FastAPI (Python/Node.js)
- **Database**: Firebase Firestore, Local JSON

## Development Tools

- **IDE**: Cursor AI / Antigravity
- **CLI**: Gemini CLI
- **Package Manager**: npm, pip, uv

## Libraries & dependencies

- **Audio Processing & TTS**: Parselmouth-praat (Pronunciation Analyzer), Kokoro-FastAPI / Kokoro-82M (Local TTS Multi-Voice Engine on port 8880)
- **Authentication**: Firebase Auth
