## 5. Visual Standards (Vault Boy Style)

All custom icons generated for the skill tree follow the **Solid White Background Vector Mascot** style:

- Thick black outlines.
- Simple cel shading / flat vector colors.
- Character: Black pompadour hair, winking, green jumpsuit with yellow trim.
- **Isolated on solid white background** for clean rendering inside the circular skill orbs.
