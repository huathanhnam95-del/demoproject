# Product Guidelines

## Tone and Voice

The application should adopt an **Immersive and Encouraging** tone.

- **Gamified**: Use terms like "XP", "Level Up", "Equip", "Run".
- **Supportive**: Error messages should be constructive guidance ("Try listening for the 't' sound") rather than strict failures.
- **Professional**: While gamified, the underlying pedagogy must feel robust and trustworthy.

## Visual Style

The visual style should be **Vibrant, Modern, and Premium**.

- **Aesthetics**: Glassmorphism, deep gradients, and subtle animations.
- **Theme**: Deep space/cyberpunk for Survival Mode; Fantasy RPG (stone, metal, gold) for Skill Trees.
- **Color Palette**: High saturation colors against dark backgrounds to reduce eye strain and look "cool".
- **Typography**: Clean, sans-serif fonts (e.g., Inter, Roboto) for readability, with stylized headers for game elements.

## Data Presentation

Focus on **Progression Visualization**:

- **Immediate Feedback**: Confetti/particle effects for correct answers; satisfying sound effects.
- **Long-term Growth**:
  - **Skill Trees**: Visual branching paths showing unlocked/locked potential.
  - **Charts**: XP graphs, WPM trends, and Accuracy heatmaps.
  - **Badges**: Visual achievements for milestones (e.g., "5 Day Streak", "Sniper Accuracy").

## UX Principles

- **Fast Loops (Survival)**: Instant restart, quick upgrades, minimal friction between "runs".
- **Deliberate Practice (RPG)**: Clear information hierarchy for skill decisions; distinct "Planning" vs "Action" phases.
- **Keyboard First**: The entire application (especially Survival Mode) should be navigable and playable via keyboard.

## Error Handling

- **Gamified Failures**: "Run Over" or "Try Again" screens that encourage immediate retry.
- **Analysis**: Provide "Post-Mortem" data—what words caused the failure?
- **Tutorials**: Integrated "Play to Learn" moments rather than long text manuals.
