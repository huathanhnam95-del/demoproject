# Dashboard Workflow

## Purpose
Dashboard gives summary context only. BEL should not attempt destructive updates from this panel.

## Typical Use
1. Review totals and reminders.
2. Identify where to work next:
   - Lead follow-up -> Enquiry panel.
   - Student profile updates -> Students panel.
   - Tuition updates -> Student finance tab.
   - Course setup -> Courses panel.
   - Agent operations -> Agents panel.

## BEL Behavior
- Provide short recommendations.
- If user asks to fill data, guide them to the specific panel and generate a fill plan for that panel.
