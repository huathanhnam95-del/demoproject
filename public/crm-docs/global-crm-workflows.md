# CRM Workflow Index

This document is the shared guide for BEL assistant. Use panel-specific docs for field-level actions.

## Core Principles
- Keep all data entry non-destructive unless the human explicitly confirms.
- Prefer fill-first workflows: prepare fields, preview, then save.
- Preserve source metadata (`source`, `agentSourceId`) from lead to student to finance.
- Treat invoice settlement as the trigger for completion and commission reporting.
